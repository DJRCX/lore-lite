# LORE Lite

LORE Lite turns project rules in Markdown files and architecture diagrams into structured, cited rules. Deterministic code resolves authority conflicts and refuses decisions when required evidence is missing.

## Status

Hackathon project scaffold. The implementation and demo instructions will be added as the build progresses.

## Planned stack

- Python 3.11+
- Gemma 4 through the Gemini API (`google-genai`)
- Pydantic, SQLite, Typer, and Streamlit
